# Roadmap

## Milestone 1 — player foundation
- [x] Media3 service and MediaSession
- [x] Direct URL playback
- [x] Queue controls and seek UI
- [ ] Build verification on Android Studio/device

## Milestone 2 — library and providers
- [ ] Room persistence for tracks, playlists and queue
- [ ] Provider adapter interface
- [ ] Search and browse screens
- [ ] Provider-compliant authentication and playback

## Milestone 3 — lyrics and artwork
- [ ] LRC and TTML parsing
- [ ] Word-level synchronisation and translation layers
- [ ] Animated artwork pipeline with memory limits
- [ ] Adaptive backgrounds and visualisers

## Milestone 4 — accounts and sync
- [ ] Supabase Auth with Google Credential Manager
- [ ] RLS-reviewed profiles, friends and settings
- [ ] Cloud listening history with offline outbox
- [ ] Discord OAuth through server-side Edge Function

## Milestone 5 — customisation
- [ ] Theme and typography engine
- [ ] Declarative, permission-limited ZIP add-ons
- [ ] Shader/effect renderer with performance controls
